# 🎮 Game Orbit

**Game Orbit** is an interactive web-based gaming platform that brings together a collection of classic arcade, puzzle, and skill-based games in one place. Built with HTML, CSS, and JavaScript, it provides an engaging and user-friendly gaming experience directly in your browser.

## 🚀 Live Demo

**Play Now:** https://siddharod.github.io/Game-Orbit/

## ✨ Features

- 🎯 **Multiple Games:** Enjoy a variety of entertaining games in one platform.
- 🕹️ **Classic Gameplay:** Experience familiar arcade and puzzle challenges.
- 🧠 **Brain Training:** Improve logical thinking, concentration, and problem-solving skills.
- 🎨 **Interactive Interface:** Navigate through a user-friendly gaming environment.
- 🌐 **Browser-Based:** Play directly from your web browser without installing a separate application.
- 💻 **Web Technologies:** Developed using fundamental front-end technologies.

## 🎲 Games Included

- **Pac-Man** – Navigate through the maze while avoiding enemies and collecting items.
- **Minesweeper** – Use logic and deduction to uncover safe cells while avoiding mines.
- **Hangman** – Guess the hidden word before running out of attempts.
- **Riddle Challenge** – Solve interesting riddles and test your reasoning skills.
- **Flappy Bird** – Navigate through obstacles and challenge your reflexes.
- **Target Shooting** – Test your aim, accuracy, and reaction time.

## 🛠️ Technologies Used

- **HTML5** – Structures the web pages and game interfaces.
- **CSS3** – Styles the application and enhances the visual presentation.
- **JavaScript** – Implements game logic, user interactions, and gameplay functionality.
- **Git & GitHub** – Used for version control and project hosting.
- **GitHub Pages** – Used to deploy the website.

## ⚙️ Getting Started

Follow these steps to run Game Orbit locally.

### Prerequisites

- A modern web browser such as Google Chrome, Microsoft Edge, or Firefox.
- Git installed on your computer (optional).

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/siddharod/Game-Orbit.git
```

**2. Navigate to the project directory**

```bash
cd Game-Orbit
```

**3. Run the project**

Open `index.html` in your web browser. Alternatively, use the Live Server extension in Visual Studio Code for local development.
